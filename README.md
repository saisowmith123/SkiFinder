# SkiFinder

SkiFinder is a simple iPad app built with SwiftUI that helps users browse ski resorts from around the world. The app is designed with a side-by-side layout to make it easy to explore resorts and view details on a larger screen.

## Features

- Browse a list of ski resorts
- View resort details in a secondary panel
- Search resorts by name
- Mark resorts as favorites
- Responsive layout for iPad and landscape mode
- Uses alerts and sheets with optional bindings

## Built With

- SwiftUI
- NavigationView
- List
- Searchable
- Alert and Sheet
- Size classes for adaptive layout

## Learning Focus

This project helped practice:

- Building side-by-side views in SwiftUI
- Creating searchable lists
- Working with `NavigationView` on iPad
- Adapting layouts based on size class
- Using `alert()` and `sheet()` with optionals
- Managing favorites in the UI
